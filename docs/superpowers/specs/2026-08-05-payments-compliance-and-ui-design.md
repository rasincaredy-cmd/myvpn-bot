# Требования платёжного провайдера + оформление интерфейса

Дата: 05.08.2026
Статус: дизайн согласован, план не написан

## Зачем

Менеджер платёжного провайдера прислал условия (карты 9%, СБП 8%, крипта 5%)
и список того, что нужно добавить в проект, чтобы продолжить согласование с
банком:

1. политика конфиденциальности;
2. пользовательское соглашение;
3. контакты поддержки (группа не подходит — нужна тикет-система, юзернейм
   или почта);
4. цены с тарифами — «чтобы было понятно, сколько и за что платит клиент».

Документы должны быть в постоянном доступе и вынесены отдельными кнопками,
«так банк сразу видит всю необходимую информацию».

Отдельное требование по категории «VPN-проекты»: убрать упоминания обхода
блокировок, глушилок, белых списков, LTE, DPI и ТСПУ. Это требование
законодательства РФ, а не прихоть провайдера. Просили убрать и упоминания ИНН
— верификацию они не проводят.

Заодно приводим в порядок внешний вид бота: сейчас главное меню — восемь
одинаковых кнопок в столбик, иерархии нет.

## Принятые решения

| Вопрос | Решение |
|---|---|
| Раздел «🛡 Обход БС» | Переименовать в «⚡ Резервное подключение», тексты переписать нейтрально. Фичу сохраняем и продолжаем продавать |
| Где документы | telegra.ph, кнопки-ссылки в боте |
| Структура меню | Три отдельные кнопки в главном меню: тарифы, политика, соглашение |
| От чьего имени документы | «Сервис Moschata VPN», без ФИО, ИНН и адреса |
| Контакт поддержки | Только встроенный тикет-чат |
| Канал сервиса | Канала нет, чистим только бота |
| Порядок работ | Документы и редизайн — одним заходом |
| Экран согласия | Да, для новых пользователей |
| Премиум-эмодзи | Отложены: у владельца бота нет Telegram Premium (проверено) |

## Часть 1. Требования провайдера

### 1.1 Переименование раздела

«🛡 Обход БС» → «⚡ Резервное подключение». Внутренняя механика (wdtt,
proxy-turn-vk, привязка к устройству, лимит `sub_max_bypass`, цена +30 ₽)
не меняется — меняются только слова, которые видит пользователь.

В тексте везде «резервное подключение», а не «обход».

### 1.2 Чистка формулировок

Полный перечень мест, где пользователь сейчас видит запрещённое.

**`bot/texts/ru.py`**

- `start_user` — убрать «без блокировок, работает даже там, где обычные VPN
  отключают»; убрать абзац «🛡 Обход БС — обход "белых списков", интернет там,
  где не спасает даже VPN». Заменить на описание через пользу: скорость,
  стабильность, несколько стран, второй способ подключения.
- `help_text` — убрать «Нужен обход "белых списков" (когда "лежит" вообще
  всё)».
- `device_created` — убрать хвост «Обход "белых списков" для этого устройства
  подключается отдельно».
- `wdtt_intro` — переписать целиком. Было: «интернет ограничивают так жёстко,
  что не открывается почти ничего… "белыми списками"… маскирует трафик под
  видеозвонок VK». Станет: «Иногда основное подключение работает нестабильно —
  низкая скорость, обрывы. Резервное использует другую технологию и в таких
  условиях часто держится лучше. Работает через отдельное приложение, не через
  AmneziaVPN».
- `wdtt_pick_device`, `wdtt_ask_platform`, `wdtt_creating`, `wdtt_created`,
  `wdtt_link`, `wdtt_revoked`, `wdtt_disabled` — «обход» → «резервное
  подключение»; из `wdtt_created` убрать финальный абзац про госсайты и VK.
- `wdtt_ask_vk` — сейчас это абзац «Маскировка под звонок VK… для оператора это
  выглядит как обычный видеозвонок, поэтому его не блокируют». Заменить на
  «Дополнительная настройка — нужна, только если её попросила поддержка».
  Кнопка «⚡ Рекомендуемый вариант» остаётся основным путём.
- `wdtt_ask_vk_link` — убрать «ссылка на звонок VK», заменить на нейтральную
  просьбу прислать адрес, который дала поддержка.

**Клавиатуры**

- `keyboards/inline/menu.py` — подпись кнопки главного меню.
- `keyboards/inline/devices.py:149` — кнопка после создания устройства.
- `keyboards/inline/wdtt.py` — «➕ Добавить обход», «« Мои обходы».

**Хендлеры**

- `handlers/devices.py:95` — «В твоём тарифе сейчас нет устройств — только
  обход БС».
- `handlers/devices.py:269` — «Доступов обхода».
- `handlers/devices.py:452, 465` — строки тарифа в карточке подписки.
- `handlers/balance.py:120` — подпись под кнопками сумм.
- `handlers/balance.py:468–474` — экран сборки тарифа.
- `handlers/balance.py:534–536` — сообщение про тариф ниже потребления.

**Планировщик** (оповещения приходят пользователю в личку)

- `services/scheduler.py:203` — «VPN и обход БС встали на паузу».
- `services/scheduler.py:260` — «чтобы устройства и обход БС не отключились».

**Названия сторонних приложений** (WDTT, VK Turn Proxy, PWDTT) остаются как
есть — пользователю нужно найти их в сторе, запрещённых слов в названиях нет.

### 1.3 Экран «💳 Тарифы»

Новый экран, доступен из главного меню без подписки и без оплаты. Сейчас цены
видны только внутри процесса покупки — банку этого мало.

Содержание: цена первой позиции, цена каждой следующей, пример типового
тарифа, скидки за срок с готовыми суммами, длительность и лимиты триала,
способ оплаты, упоминание автопродления и того, что его можно отключить.

Все цифры подставляются из `settings` и `pricing.py`, а не пишутся в тексте
намертво: поменяется цена — экран обновится сам.

### 1.4 Документы

Две страницы на telegra.ph. Кнопки в меню ведут на них напрямую.

**Политика конфиденциальности:** какие данные собираются (Telegram-ID, имя,
username, платежи, объём трафика), какие не собираются (история посещений,
содержимое трафика, логи подключений), цели обработки, сроки хранения,
удаление данных по запросу (механика уже есть — `user_wipe`), передача третьим
лицам (платёжный провайдер получает только факт оплаты).

**Пользовательское соглашение:** предмет (доступ к VPN-сервису по подписке),
порядок оплаты с внутреннего баланса, автопродление и его отключение,
возвраты, обязанности пользователя, ограничение ответственности, изменение
условий, порядок связи через поддержку.

Оба документа — от имени «сервиса Moschata VPN», без ФИО, ИНН и адреса,
с указанием актуальной даты. Единственный контакт — тикет-чат в боте.

Порядок публикации: сначала тексты показываются Владу, после его вычитки
создаются страницы. Токен telegra.ph сохраняется — без него страницы потом
не отредактировать.

### 1.5 Экран согласия при первом входе

Новый пользователь при первом `/start` видит короткий текст оферты и кнопки:
«Пользовательское соглашение», «Политика конфиденциальности», затем «Согласен»
/ «Не согласен». Триал и главное меню выдаются только после согласия.

Отказ — вежливое сообщение о том, что без принятия условий сервис
недоступен, с возможностью вернуться к экрану позже.

Факт согласия пишется в БД с датой: новая колонка `users.terms_accepted_at`,
добавляется автомиграцией (`ALTER TABLE ADD COLUMN`, без `REFERENCES`).
Действующих пользователей не трогаем — гейт только для новых.

Внимание при реализации: `PRAGMA foreign_keys` не включать, на выключенных FK
держится `user_wipe`.

### 1.6 Контакты поддержки

Тикет-чат уже работает и формально закрывает требование. Меняется только
экран «🆘 Поддержка»: явная формулировка о том, что это официальный канал
обращений по любым вопросам, включая оплату и возвраты. Время ответа не
обещаем цифрой — сервис ведёт один человек. Место под почту оставляем на
случай, если банк попросит второй канал связи.

## Часть 2. Оформление

### 2.1 Цветные кнопки

Проверено на проде: aiogram 3.28.2, поле `style` (Bot API 9.4) сервер
принимает и возвращает. Палитра фиксированная — `success`, `primary`,
`danger`. Старые клиенты покажут обычные кнопки, ничего не ломается.

Раскраска по смыслу, а не для пестроты:

- `success` — «Продлить подписку», «Пополнить баланс», «Согласен»;
- `primary` — «Мои устройства», «Добавить устройство»;
- `danger` — удаление устройства, отзыв доступа, «Не согласен»;
- без цвета — навигация («В меню», «Назад») и справочные разделы.

### 2.2 Раскладка меню

Сейчас всё через `kb.adjust(1)` — восемь одинаковых кнопок в столбик.
Станет: главные действия во всю ширину, второстепенные — парами в ряд.

Черновая раскладка главного меню:

```
📱 Мои устройства            (во всю ширину, primary)
⚡ Резервное подключение     (во всю ширину)
🎫 Моя подписка   |   💰 Баланс
💳 Тарифы         |   🌍 Локации
🔔 Оповещения     |   🆘 Поддержка
📄 Политика конфиденциальности
📜 Пользовательское соглашение
👮 Админ-панель              (только админам)
```

### 2.3 Статус подписки на главном экране

Сейчас за сроком надо идти в «🎫 Моя подписка». Добавляем в текст главного
меню две строки: активна ли подписка и сколько дней осталось. Данные уже
есть в `users.sub_expires_at`.

### 2.4 Премиум-эмодзи — отложено

Проверено отправкой через бота: премиум-эмодзи не проходят вовсе — 0 из 50
из списка Влада и 0 из 3 эталонных, которые Telegram отдаёт сам через
`getForumTopicIconStickers`. Причина не в списке, а в правах: с 09.02.2026
их разрешено использовать, только если у владельца бота активен Telegram
Premium. Иконки на кнопках (`icon_custom_emoji_id`) сервер принимает, но
клиент их не рисует — Влад подтвердил визуально.

Поэтому: тексты пишутся с обычными эмодзи, а поддержка премиум-версии
закладывается настройкой `PREMIUM_EMOJI_ENABLED` в `.env` (по умолчанию
выключена). Когда Premium появится — включаем флаг и прогоняем тот же
тест по списку ID, переписывать экраны не придётся.

## Часть 3. Что осознанно не трогаем

Админ-панель: «🛡 Обходы сервера», «Лимит обходов», «Обход БС: ВКЛ» и прочее.
Это внутренние экраны, проверяющему из банка они недоступны. Переименование
удвоило бы объём правок без пользы. Если попросят демо-доступ — вернёмся.

Комментарии в коде и README тоже остаются: это не то, что видит пользователь.

## Часть 4. Проверка

- Тексты: тест, который проходит по всем строкам `texts/ru.py` и подписям
  пользовательских клавиатур и падает при встрече стоп-слов (обход,
  блокировк, белы(й|х) спис, DPI, ТСПУ, глушилк, LTE, ИНН). Он же защитит от
  возврата формулировок в будущем. Админские клавиатуры (`inline/admin.py`,
  `inline/servers.py`) в проверку не включаются — там формулировки остаются
  по решению из части 3.
- Гейт согласия: новый пользователь без согласия не получает триал и меню;
  после согласия дата записана; действующий пользователь гейт не видит.
- Экран тарифов: цифры совпадают с `pricing.py` при изменении цен в `.env`.
- Ссылки на документы открываются.
- Ручная проверка на живом боте: как выглядят цвета и раскладка на телефоне.
